# Memes Theft Auto ($MTA)

Official website of $MTA, the heist memecoin on Solana. Launch: 19.11.2026.

Static site served by GitHub Pages from the `main` branch (root).

## Launch day
Everything that changes at launch lives in the `CONFIG` block at the top of the main script in `index.html`:

- `CONTRACT`: token mint address (shows the address, turns the security checks green, links Jupiter / DexScreener / Solscan, opens the live chart section)
- `X_URL`, `TG_URL`: official socials
- `LAUNCH_AT`: exact launch time (Paris)
- `DEV_BUY_PCT`: % of supply bought by the team at launch
